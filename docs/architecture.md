# المعمارية

## الحالة الحالية

المستودع يوفّر سجلًا وصفيًا، سياسة افتراضية، مخطط JSON، ومدققًا محليًا. لا يوجد runtime أو واجهة مستخدم أو اتصال بمزود نموذج أو خادم خارجي. أي تعريف في السجل هو بيانات وصفية وليس أمر تشغيل.

## المكونات

1. **سجل الوكلاء (`agents/registry.json`)**: قائمة تعريفات فارغة عند الإنشاء. لا تُخزن فيها مفاتيح أو بيانات اعتماد.
2. **عقد الوكيل (`schemas/agent.schema.json`)**: يحدد الحقول والقدرات المقبولة قبل إضافة تعريف.
3. **محرك السياسة (`policies/default.json`)**: الوضع `disabled`، مع قائمة سماح ومجموعة أفعال محظورة.
4. **المدقق (`ai_agents_hub/`)**: يفحص ملفات JSON واتساقها محليًا؛ لا يفتح اتصالات شبكة ولا يشغّل تعليمات وكيل.
5. **CI (`.github/workflows/ci.yml`)**: يختبر المدقق على تغييرات الفروع وطلبات السحب، بصلاحية `contents: read` فقط.

## دورة الحياة المستهدفة لاحقًا

`draft → policy review → human approval → limited pilot → audit → (optional) enablement`

هذه الدورة توثيق تخطيطي فقط. لا يوجد في الإصدار الحالي مسار يفعّل التنفيذ أو يمنح صلاحيات تلقائيًا.

## حدود المسؤولية

- لا يتولى هذا المستودع إدارة حسابات مزودي النماذج أو مفاتيحهم.
- لا يقرأ مستودعات خاصة أخرى ولا ينفذ أدوات أو أوامر خارجية.
- لا يدمج Pull Requests ولا ينشر إنتاجًا ولا يتعامل مع محافظ أو أموال.
- ينبغي فصل أي runtime مستقبلي عن مخزن التعريفات، واستخدام هوية قصيرة العمر وصلاحيات ضيقة بعد مراجعة أمنية مستقلة.
