# خارطة الطريق

## المرحلة 0 — الأساس الآمن (الحالية)

- مستودع خاص وهيكل واضح.
- سجل وكلاء ومخطط وسياسة افتراضية معطلة.
- مدقق محلي واختبارات وCI محدود الصلاحيات.
- لا تشغيل، ولا مزود نماذج، ولا أسرار، ولا نشر.

## المرحلة 1 — الحوكمة والتوثيق

- اعتماد مالك ومراجعين وسياسة تغيير.
- توسيع المخططات ومراجعتها أمنيًا.
- إضافة سجل تغييرات وموافقات يدوية قابلة للتدقيق.

## المرحلة 2 — لوحة قراءة فقط

- عرض حالة التعريفات والسياسات وسجل التغييرات.
- مصادقة وصلاحيات على مستوى الدور والمشروع.
- لا أوامر تنفيذية أو كتابات إلى الأنظمة الخارجية.

## المرحلة 3 — تجربة محدودة

- اختيار مزود نموذج بعد قرار صريح.
- حفظ مفاتيح الوصول خارج المستودع واستخدامها بأقل صلاحيات.
- بيئة معزولة، حدود موارد، ومراجعة بشرية إلزامية للمخرجات.

## المرحلة 4 — تقييم قبل التوسع

- اختبارات red-team وprompt injection.
- قياس الاعتمادية والتكلفة والتسريب وإمكانية الإيقاف.
- لا تُفعّل إجراءات الإنتاج أو المالية تلقائيًا؛ تحتاج نطاقًا وقرارًا مستقلين.

كل مرحلة تتطلب مراجعة بشرية قبل الانتقال إلى التالية.
