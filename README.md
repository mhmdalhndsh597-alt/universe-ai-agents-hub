# مركز الكون لإدارة وكلاء الذكاء الاصطناعي

**Universe AI Agents Hub** — بنية تأسيسية آمنة لتسجيل وكلاء الذكاء الاصطناعي ومراجعة صلاحياتهم وحالاتهم.

> **حالة المشروع:** أساس أولي خاص. لا يشغّل وكلاء أو يستدعي نماذج ذكاء اصطناعي حاليًا، ولا يحتوي على مفاتيح أو أسرار.

## الرؤية

بناء مركز موحّد يساعد على تعريف الوكلاء، مراجعة قدراتهم، وضبط دورة حياتهم ضمن سياسات واضحة وقابلة للتدقيق. يبدأ هذا المستودع بسجلّ وصفي ومتحقق سياسات، مع تعطيل التنفيذ افتراضيًا وإبقاء أي إجراء مؤثر تحت موافقة بشرية صريحة.

## مبادئ الأمان

- **التعطيل افتراضيًا:** `execution_mode` مضبوط على `disabled` ولا يوجد منفّذ وكلاء في هذه النسخة.
- **أقل صلاحية:** القدرات الوصفية محدودة بقائمة سماح؛ لا تُمنح صلاحيات كتابة أو تشغيل أو وصول للأسرار.
- **موافقة بشرية:** أي قدرة مستقبلية ذات أثر خارجي تتطلب مراجعة وموافقة بشرية.
- **منع الأسرار والآثار المالية:** لا مفاتيح API أو SSH في المستودع، ولا توقيع معاملات أو إرسالها أو تحويل أموال أو نشر إنتاجي.
- **قابلية التدقيق:** يبدأ كل تعريف وكيل من سجل JSON يمكن التحقق منه واختباره في CI.

## ما يتضمنه الأساس الحالي

| المكوّن | الغرض |
|---|---|
| `agents/registry.json` | سجل أولي فارغ لتعريف الوكلاء؛ لا يوجد وكيل مفعّل |
| `policies/default.json` | سياسة تعطيل افتراضي وقائمة قدرات مسموحة/ممنوعة |
| `schemas/agent.schema.json` | مخطط تعريفي لعقد الوكيل |
| `ai_agents_hub/` | مدقق محلي يتحقق من الحقول والأنواع والحدود والتكرار واتساق الصلاحيات بين الملفات، بلا اتصال شبكي |
| `tests/` | اختبارات تحقق من الحالات السليمة والخطرة |
| `.github/workflows/ci.yml` | فحوص محلية على GitHub Actions بصلاحية قراءة فقط ودون أسرار |
| `docs/` | بنية النظام ونموذج الأمان وخارطة الطريق |

## البدء محليًا

يتطلب Python 3.12 أو أحدث، ولا يحتاج إلى حزم خارجية:

```bash
python -m unittest discover -s tests -v
python -m ai_agents_hub validate
```

لإضافة تعريف، ابدأ بتعديل `agents/registry.json`، ثم راجع `policies/default.json` و`schemas/agent.schema.json`. الإضافة إلى السجل **لا تشغّل الوكيل**؛ التنفيذ غير متوفر في هذه المرحلة.

## البنية

```text
agents/registry.json       تعريفات وصفية فقط
schemas/                  عقود JSON
policies/                 سياسات افتراضية fail-closed
ai_agents_hub/            أدوات تحقق محلية
 tests/                    اختبارات دون اتصال شبكي
docs/                     معمارية وأمان وخارطة طريق
.github/workflows/         CI محدود بصلاحية القراءة
```

## خارطة الطريق

1. تثبيت نموذج التهديد وحدود الصلاحيات ومراجعة ملكية المشروع.
2. تطوير لوحة قراءة فقط لسجل الوكلاء وسجل التدقيق.
3. إضافة تكاملات مزودي النماذج بعد تحديد المزود وإدارة الأسرار خارج Git.
4. تصميم موافقات بشرية وسجل تدقيق قبل أي تشغيل تجريبي محدود.
5. عدم تمكين إجراءات إنتاجية أو مالية أو على السلسلة ضمنيًا.

## English summary

**Universe AI Agents Hub** is a private, security-first foundation for registering and reviewing AI-agent definitions. This scaffold does not execute agents, call model providers, access secrets, or perform external actions. Execution is disabled by default; CI runs local validation and tests with read-only repository permissions.
