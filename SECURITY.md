# Security Policy

## Supported scope

Security reports are welcome for the repository’s code, validation rules, GitHub Actions workflow, and documented policies. This project is currently a non-executing scaffold; it does not call model providers or connect to external systems.

## Reporting

Please do not publish exploit details, credentials, or sensitive data in a public issue. Use GitHub’s private vulnerability reporting feature for this repository if it is enabled. Otherwise contact the repository owner through a private GitHub channel and include reproduction steps with secrets removed.

## Secrets

Never commit API keys, access tokens, SSH private keys, wallet keys, or production credentials. Revoke and rotate any credential that may have been exposed; do not paste it into an issue or pull request.
