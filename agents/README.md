# سجل الوكلاء

`registry.json` هو سجل وصفي فقط. أضف تعريفًا مطابقًا لـ`schemas/agent.schema.json` بعد مراجعة السياسة، واترك `enabled` مضبوطًا على `false` ما لم تُعتمد مرحلة تشغيل منفصلة رسميًا.

لا تضع هنا prompts سرية أو مفاتيح أو بيانات شخصية أو تعليمات تنفيذية عالية الأثر. إضافة تعريف إلى السجل لا تشغّل وكيلًا في هذا المشروع.
